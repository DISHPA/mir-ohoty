# МИР ОХОТЫ

Онлайн-мир от третьего лица: бесконечный раннер, который вырос в свободную арену
400×400. Монстры охотятся на тебя, ты охотишься на них — и всё это вместе с другими
игроками в реальном времени: чат, дуэли, призраки-союзники.

**Играть:** https://dishpa.github.io/mir-ohoty/ (GitHub Pages, публичные MQTT-брокеры)
**Локально с ретранслятором:** `node serve.mjs` → http://127.0.0.1:8902/run/

## Что внутри

- **Мир.** Свободное перемещение по плоскости XZ, полярная переработка декораций и
  дальней линии горизонта — мир не кончается. `R.tier = 1 + floor(R.dist / 130)`
  масштабирует HP мобов, их урон, плотность и награду.
- **Бой.** Три скилла (удар, рывок, вихрь), крит, броня, компаунд-урон, отбрасывание
  и раздавливание (с `tier ≥ 12` мобы бьют на 5 % максимального HP каждые 0.9 с).
  Регенерация ограничена сверху, чтобы нельзя было отсидеться.
- **Прокачка и крафт.** Магазин на 12 линий (скорость, атака, урон, золото, HP,
  раздавливание, регенерация, крит, броня, перезарядка, банк, удача), крафт
  снаряжения, сохранение в `localStorage` под ключом `hrunner_v1`.
- **Онлайн.** Свой чат, список игроков, дуэли с денежным выигрышем, аватары-клоны
  героя с подписями над головой. Транспорт выбирается сам:
  - свой сервер → **ретранслятор** `ws(s)://<host>/ws` (`bot/relay.mjs`);
  - GitHub Pages / статика → **публичные MQTT-брокеры** (emqx, mosquitto, hivemq)
    с автоматическим переключением и самовосстановлением `mqtt.js`.
- **Telegram.** `bot/server.mjs` — Mini App-хостинг + бот без единой npm-зависимости.

## Сборка

Всё в одном файле — офлайн, без CDN:

```
node run/build.mjs      # src/a.txt + three.js + glTFLoader + модели + игра + онлайн → run/runner.html, run/index.html
node --check run/check.js
```

`src/a.txt` — HTML/CSS до `<script>`, `src/b.txt` — игра, `src/online.txt` — сеть,
`src/mqtt.js` — транспорт (Relay | mqtt.js), `src/mqttlib.min.js` — mqtt@5.10.1 UMD.

## Онлайн-сервер

```
node serve.mjs          # статика + /ws на 8902 (для локальных тестов)
```

`bot/relay.mjs` — WebSocket-ретранслятор на 250 строк: свой HTTP-upgrade, разбор
RFC 6455 (маска, 126/127-длины), комнаты, ping/pong, лимит 4000 символов.
`attachRelay(server, '/ws')` вешается и на `serve.mjs`, и на `bot/server.mjs`.

## Бот

Самое короткое — скрипт-обёртка (сам найдёт node из комплекта DSH и проверит токен):

```powershell
cd bot
.\start.ps1                                    # спросит токен
.\start.ps1 -Token 8123456789:AAH... -PublicUrl https://xxx.up.railway.app
```

Вручную:

```
BOT_TOKEN=... PUBLIC_URL=https://... PORT=8080 node bot/server.mjs
```

Пошагово, включая получение токена у @BotFather и варианты хостинга: `bot/ЗАПУСК.md`.
Без `BOT_TOKEN` сервер всё равно поднимается и раздаёт игру с ретранслятором; если
Telegram недоступен из сети, процесс не падает, а только пишет в лог.

## Известные ограничения

- На GitHub Pages нет `/ws`, поэтому онлайн идёт через публичные брокеры: работает,
  но зависит от их доступности в твоей сети.
- Ретранслятор в памяти: при перезапуске комнаты пустеют (это нормально — клиенты
  переподключаются сами).
- Нет аккаунтов: имя генерируется на страницу, прогресс живёт в `localStorage`.
